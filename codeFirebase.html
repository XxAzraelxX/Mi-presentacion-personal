Curso Avanzado de Firebase

Completado en el primer semestre del 2025. Se llevo acabo un estudio sobre Firebase cubriendo diversos aspectos avanzados del desarrollo con Firebase, incluyendo:

  • Autenticación de usuarios y gestión de sesiones, por google y correo electrónico.
  • Uso de Firebase Realtime Database y Cloud Firestore.
  • Implementación de notificaciones push con Firebase Cloud Messaging.
  • Gestión de usuarios y control de acceso con Firebase Authentication.
  • Implementación de Firebase Analytics para el análisis de aplicaciones móviles.

Gracias a este estudio, adquirí conocimientos necesarios para integrar Firebase en aplicaciones móviles y mejorar su rendimiento y escalabilidad.
